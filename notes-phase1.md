# 🧠 What I Learned

## What is Backend?

Backend is the part of an application responsible for:

- Business Logic
- Database Operations
- Authentication
- APIs
- Server-side Processing

The backend communicates with databases and sends responses to the frontend.

---

## Client-Server Architecture

```
Client
   │
HTTP Request
   │
Server
   │
Business Logic
   │
Database
   │
HTTP Response
   │
Client
```

The client requests data.

The server processes the request and returns a response.

---

## What is HTTP?

HTTP (HyperText Transfer Protocol) is the communication protocol used between clients and servers.

Common HTTP Methods:

- GET
- POST
- PUT
- DELETE

---

## API

API stands for

Application Programming Interface.

It allows two software applications to communicate with each other.

Example:

```
Mobile App
      │
 REST API
      │
Spring Boot Backend
      │
Database
```

## JDK vs JRE vs JVM

### JVM

Runs Java bytecode.

---

### JRE

Contains:

- JVM
- Java Libraries

Used for running Java applications.

---

### JDK

Contains:

- JRE
- Java Compiler
- Development Tools

Used for developing Java applications.

# 📂 Git Basics

Git is a Version Control System.

GitHub is a cloud platform used to store Git repositories.

Basic workflow

```
Working Directory
        │
git add
        │
Staging Area
        │
git commit
        │
Local Repository
        │
git push
        │
GitHub
```
